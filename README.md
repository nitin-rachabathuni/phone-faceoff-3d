# Phone Face-off 3D

iPhone Duo vs Pixel 11 Pro vs Galaxy S26, as a developer's scorecard in pure HTML + CSS 3D.

Live: https://nitin-rachabathuni.github.io/phone-faceoff-3d/

## Why this exists

Spec sheets are boring. Opinions are useful. This is both, on one page, with no framework.

- CSS `perspective` + `preserve-3d` cards
- Pointer tilt, click to flip
- `?demo=1` auto-plays the flips
- `?reel=1` vertical 1080x1920 layout with a timed script + captions (used to record the Instagram reel)

## Run

Open `index.html`. That is it.

## Numbers

Prices, weights, batteries, and chips are from public spec listings in mid-October 2026. Verdicts are mine.

## Reuse

MIT. Fork it for your own three-way comparison. Swap the specs, keep the CSS.
